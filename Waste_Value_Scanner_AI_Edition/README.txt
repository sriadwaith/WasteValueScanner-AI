WASTE VALUE SCANNER — AI EDITION

1. Extract the ZIP.
2. Open index.html in Chrome or Edge.
3. Keep internet ON the first time so TensorFlow.js + MobileNet can load from the CDN.
4. Open Scan Waste.
5. Upload a clear image with one main object.
6. Click Analyze with AI.

The site uses TensorFlow.js + MobileNet for genuine browser-side image classification. MobileNet is a general ImageNet model, not a waste-specific model, so its predictions are mapped into waste pathways. Demo Mode is available for a reliable competition presentation.

For the strongest final competition version, replace MobileNet with a waste-specific classifier trained on bottle/can/cardboard/glass/paper/e-waste images.
